## 🚀 Como Carregar no Teclado Yamaha PSR-E433

1. **Prepare o Pendrive:**
   * Formate um pendrive USB no formato **FAT** ou **FAT32**.
   * Copie as pastas ou os arquivos `.STY` para o pendrive.
2. **Conecte no Teclado:**
   * Insira o pendrive na entrada **[USB TO DEVICE]** na parte traseira do PSR-E433.
3. **Carregamento via Painel:**
   * Pressione o botão **[FUNCTION]** repetidamente até aparecer na tela a opção **`Load Style`**.
   * Pressione **[EXECUTE]**.
   * Gire o dial central ou use os botões `+ / -` para escolher o arquivo desejado (ex: `PISEIRO_BAROES_SHOW.STY`).
   * Pressione **[EXECUTE]**.
   * Escolha o número da memória de usuário para salvar (no PSR-E433 são as posições de **187 a 191**).
   * Pressione **[EXECUTE]** e confirme com **[EXECUTE]** (Load OK).
4. **Para Tocar:**
   * Pressione o botão **[STYLE]**, selecione o número da posição (ex: 187), ligue o **[ACMP]** (Acompanhamento) e toque os acordes com a mão esquerda!
